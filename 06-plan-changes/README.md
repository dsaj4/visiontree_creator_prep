# 计划修改记录

本目录存储计划新增、替换、删除和重排的依据。

## 职责

- 记录计划修改来源、目的、影响账号和同步状态。
- 为 `content-system` 的计划日历提供人工可读依据。
- 保留“只改计划，不创建内容草稿”的边界。

## 禁止事项

- 不在这里写最终发布文案。
- 不把计划修改同步成 `contents` 草稿。
- 不写 `publishedAt`、平台指标或发布结果。
- 不绕过 `content-system` 计划 API 直接伪造内容库状态。

## 同步状态

- `未同步`：只在计划修改记录中存在。
- `待同步`：计划字段已确认，可以更新到 `content-system.plans`。
- `已同步`：已经进入 `content-system` 计划日历。
- `废弃`：不再执行，但保留记录。

## 推荐文件名

```text
YYYY-MM-DD-topic-plan-change.md
```

## 字段要求

每个计划修改文件至少包含：

- 修改原因
- 生效日期和时间
- 涉及账号
- 新增/替换/删除的计划 ID
- 计划字段：date、day、slot、channel、theme、owner、goal、status
- 是否需要删除旧计划
- 同步状态
- 内容库边界说明
