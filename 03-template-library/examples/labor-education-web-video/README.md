## 项目背景

这个案例把一份“劳动教育结课报告”做成 16:9 点击驱动网页演示，用于录屏生成视频。内容不走传统 PPT 路线，而是以校园真实劳动素材、口播节拍和纪录片式视觉节奏来承载完整汇报。

它证明 `web-video-presentation` 模板不仅能做技术解释和产品 talk，也适合把个人经历、课程汇报、实践复盘等素材做成更有画面感的视频化表达。

## 运行效果

- 最终形态：1920×1080 固定 16:9 网页舞台，点击或方向键推进。
- 内容结构：9 个章节，覆盖开场、理论学习、校园实践、劳动细节、团队协作、心态变化、自我反思、生活态度、结尾。
- 交互方式：手动点击推进；代码中已包含 `manual`、`audio`、`auto` 三种播放模式。
- 录屏口径：页面 chrome 尽量隐藏，只保留轻量进度反馈，适合录成 3-5 分钟视频。
- 视觉气质：温暖、真实、校园纪录片感；避免汇报 PPT 感和营销页感。

## 使用边界复盘

适合：

- 已有完整口播稿、文章或报告，需要变成视频化网页演示。
- 素材有真实画面或可生成补充画面，能支撑章节视觉。
- 内容需要逐步展开，不适合一次性铺满信息。
- 创作者愿意先确认脚本、outline 和视觉方向，再进入网页制作。

慎用：

- 只有一句主题，没有材料、段落、例子或视觉素材。
- 时间非常短，只需要一张海报或短帖。
- 内容必须大量展示表格、密集参数或实时数据。

不适合：

- 纯公告、纯口号、纯营销落地页。
- 需要复杂交互应用而不是录屏视频舞台。
- 不能接受人工检查点，要求从输入到成片全自动一次跑完的任务。

## 可迁移方法

1. 先把长稿改成自然口播稿，不直接从原文做网页。
2. 再把口播拆成章节，每章 2-4 个 step，每个 step 只放一个想法。
3. 用 `style-guide.md` 先锁定视觉气质，避免工程阶段反复换风格。
4. 建 `asset-inventory.md`，把真实素材、生成素材和待补素材分开。
5. 第 1 章先做成完整样板，再扩展到后续章节。
6. 截图至少保留桌面开场、移动端开场、一个正文场景，方便模板库展示运行效果。
